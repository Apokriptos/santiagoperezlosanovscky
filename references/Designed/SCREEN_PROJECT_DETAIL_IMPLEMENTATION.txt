===============================================================================
1. CORE DESIGN PRINCIPLE
===============================================================================

Project Detail is where the established system becomes more tactile.

Formula:
    GUILTY GEAR AROUND THE COMPONENTS
    + NINTENDO-LIKE CLARITY / TACTILITY INSIDE THE COMPONENTS

This means:
- expressive shell / rails / edge decoration
- strong black/red headings
- chunky tactile panels
- layered depth
- obvious action zones
- clean readable interiors
- standard media geometry
- minimal ambiguity

Do NOT:
- turn media into trapezoids or irregular crops
- distort screenshots/video to fit decorative framing
- use flat bordered rectangles as the only panel treatment
- invent giant poster-like composition changes
- create excessive bespoke polygon shapes
- add genre chips unless project data actually provides them
- add descriptive sections not present in the existing project structure
- place redundant carousel arrows below media
- place dot indicators below the screenshot carousel

===============================================================================
12. DEPTH / NINTENDO-LIKE TACTILITY
===============================================================================

This screen must NOT fall back to flat white rectangles.

Each panel should feel assembled from layers:

    base card
    + raised header plate
    + clean body
    + inset strip / action zone where needed
    + compact shadow
    + red depth accent

Use:
- chunky readable surfaces
- obvious internal grouping
- stronger button affordances
- physical hover / pressed feedback
- clean, friendly spacing
- mild corner clipping / bevel-like construction

Do not:
- use glassmorphism
- use large blurred shadows
- overcomplicate every edge
- create ornamental borders that interfere with media or text

===============================================================================
15. INTERACTIONS
===============================================================================

Panels:
- no hover unless panel itself is interactive

Buttons:
REST:
    clear physical depth

HOVER:
    slight lift / stronger edge / arrow emphasis

PRESSED:
    subtle compression / reduced shadow

FOCUS:
    obvious keyboard-visible focus

Gallery arrows:
- semantic buttons
- aria-label previous / next
- vertically centered on media
- large hit area

Index tabs:
- semantic buttons/links
- current item exposed programmatically


===============================================================================

===============================================================================

Desktop:
    composed two-column / two-row layout

Tablet:
    allow grid to compress
    media remains standard ratio
    panels remain readable

Mobile:
    normal vertical document flow
    stack sections in logical order:
        title
        video
        The Game
        gallery
        gallery index
        Playable Build
